Privacy Policy

NeuroClips · last updated 13 September 2026 · home

Summary

NeuroClips is a personal, self-hosted tool with exactly one user: the person who installed it. It collects no data from anyone else, has no visitors, no sign-ups and no analytics. This policy exists because Google requires one from applications that use the YouTube API.

What the application accesses

With the operator’s explicit consent through Google’s own sign-in screen, NeuroClips requests:

  • youtube.upload — to upload videos to the operator’s own channel
  • youtube.readonly — to read that channel’s video list, so the same video is not uploaded twice
  • yt-analytics.readonly and yt-analytics-monetary.readonly — to read that channel’s own view counts and estimated revenue, shown privately to the operator

It requests nothing else and can reach no account other than the one that authorised it.

What is stored, and where

  • The OAuth token is stored on the operator’s own computer in a file readable only by them, and as an encrypted GitHub Actions secret used to run the uploads. It is never displayed, logged or transmitted anywhere except to Google.
  • Video records — titles, upload dates, YouTube video IDs, view counts and estimated earnings for the operator’s own channel — are stored in a local database file, kept in a private repository.
  • Nothing else. No personal data about any other person is collected, processed or stored.

Who the data is shared with

No one. Data is not sold, rented, published, or disclosed to third parties. It is not used for advertising, and it is not used to train machine-learning models. The only outbound transfers are the API calls to Google that the application exists to make.

Limited use

NeuroClips’ use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

The operator can revoke the application’s access at any time at myaccount.google.com/permissions, which immediately ends all access. Local copies are removed by deleting the application’s folder; there is no server-side copy to request the deletion of.

Children

The application is not directed at children and has no users other than its operator.
